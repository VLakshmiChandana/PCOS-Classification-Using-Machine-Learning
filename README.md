# PCOS-Classification-Using-Machine-Learning
Domain: Healthcare AI / Machine Learning 
Tech Stack: Python, Pandas, NumPy, Scikit-learn 
Tools/Platforms Used: Jupyter Notebook

Machine learning-based PCOS classification using medical data and ultrasound image features.
Developed a machine learning-based PCOS classification system to support early and accurate detection using medical data and ultrasound image features. Performed data preprocessing, feature extraction, model training, and evaluation to improve classification performance. Evaluated the model using standard performance metrics to ensure reliable prediction accuracy. This project strengthened my skills in data preprocessing, supervised learning, model evaluation, and healthcare AI applications.
